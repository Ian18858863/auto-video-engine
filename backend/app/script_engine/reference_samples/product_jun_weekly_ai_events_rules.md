## 核心判断

这个系列的核心能力不是资讯搬运，而是：

```text
技术事件 -> 普通人处境 -> 强场景钩子 -> 证据画面快剪 -> 一句判断字幕
```

高播放样本共性：

- 技术主体被人格化：AI 当老板、AI 替你相亲、AI 结婚、Agent 打工。
- 抽象能力被场景化：不是“智能体能力提升”，而是“24 小时给你打工”。
- 事件有金钱/工作/关系/身体/生存感：赚钱、相亲、老板、女友、结婚、跑滴滴。
- 标题里有具体名词和动作：龙虾、拔网线、开公司、跑滴滴、结婚。
- 第一条不是最专业的，而是最能让人停下来的。

低播放样本共性：

- 标题停留在能力层：最强同声传译、AI 正常说话、口语陪练。
- 事件本身有价值，但没有被翻译成普通人的损益或处境。
- 更像工具更新列表，而不是故事入口。

## 适配 Ian 的内容方向

适合迁移：

- 每日 AI 大事。
- 每日财经 + AI + 商业新闻合集。
- 多热点 3-5 条合集。
- 一个大主题下的 8-12 个快速信息点。

谨慎迁移：

- 严肃灾难、公共事件、政策新闻。
- 需要专业审慎判断的财经/投资内容。

迁移原则：

```text
学“翻译机制”，不要学“梗本身”。
学“证据密集”，不要学“纯猎奇”。
学“短句封面”，不要学“夸张断言”。
```

## 爆点评分规则

脚本引擎在多条热点里选开头时，优先给每条候选打分：

| 维度 | 权重 | 高分表现 |
|---|---:|---|
| 普通人处境感 | 25 | 关系、工作、赚钱、身体、时间、家庭、身份 |
| 具体动作感 | 20 | 结婚、打工、开公司、跑滴滴、拔网线、替你做事 |
| 反常识/离谱感 | 15 | 观众会想“这也行？” |
| 大公司/名人背书 | 15 | OpenAI、Google、Claude、马斯克、英伟达等 |
| 画面证据可得性 | 15 | 有官网、论文、演示、榜单、产品截图 |
| 与账号方向匹配 | 10 | 能落到普通人的判断，不只是热闹 |

开头事件选择：

```text
lead_event = score_top_1
如果 score_top_1 只有模型名/产品名，没有处境感，则降级。
如果 score_top_2 处境感明显更强，优先用 score_top_2 做开头。
```

## 推荐结构

### 多热点合集型

适合每日新闻、AI 大事、财经大事。

```text
0-3s：强钩子
3-12s：本期总判断
12-45s：第 1 条，最有场景感/冲突感
45-75s：第 2 条，大公司/大趋势
75-105s：第 3 条，工具/产品能力
105-135s：第 4 条，财经/商业/普通人影响
135-165s：第 5 条，补充信息或反常识案例
165-180s：一句总结 + 轻 CTA
```

当前样本时长主要在 104-206 秒。Ian 的合集可优先控制在：

- 3 条：90-120 秒。
- 5 条：140-190 秒。
- 8-10 条：180-240 秒。

### 单选题深挖型

产品君样本不是深挖型，但可迁移开头方式：

```text
0-3s：用普通人处境开场
3-15s：解释发生了什么
15-45s：给证据
45-90s：解释为什么重要
90-130s：普通人应该怎么看
130-150s：总结判断
```

## 开头钩子规则

不要从公司名或模型名开头。

弱开头：

```text
OpenAI 发布了新的智能体模型。
Google 上线了新的口语陪练功能。
Claude 又升级了。
```

强开头：

```text
这周 AI 最离谱的事，不是模型又变强了，而是它已经开始替人相亲了。
一个 AI Agent 只花 7 小时赚了 1 万美元，赚不到钱还会被拔网线。
如果你还把 AI 当聊天工具，这周的新闻已经不是这个阶段了，它开始像员工、老板和对象了。
```

可复用公式：

```text
这周/今天最值得看的，不是 A，而是 B。
如果只看一条，先看这条：B。
B 听起来像段子，但它背后其实是 C。
过去我们以为 AI 只能 A，现在它开始 B。
这件事真正重要的不是 A，而是 B。
```

## 文案风格规则

语气：

- 快。
- 白话。
- 判断明确。
- 不解释过多背景。
- 不每条都展开，只留下能记住的一句话。

句式：

```text
谁 + 做了什么 + 为什么值得看
工具名 + 人话翻译 + 可能影响
一个反常识事实 + 一个简短判断
```

每条信息的推荐口播结构：

```text
【标签】第一条，X。
【事实】谁发布/开源/上线了什么。
【翻译】这东西简单说，就是能让你/公司/普通人做到什么。
【判断】所以它不是一个小功能，而是某个流程开始自动化。
```

## 标题和封面分工

标题负责完整信息，封面负责停留。

标题可以写：

```text
盘点今日 AI 大事｜Google 上线 AI 口语陪练
今日 5 件事｜AI 员工、人民币汇率、OpenAI 新模型
```

封面文案要更短、更像场景：

```text
AI 替你相亲
AI 给你打工
机器人开公司
AI 开始做 PPT
房价逻辑变了
工资被 AI 重定价
```

封面规则：

- 固定系列标签。
- 一行主题标签 + 一行强钩子。
- 钩子 6-10 个字优先。
- 只放一个主爆点，不把所有信息塞进封面。
- 封面文案和标题可以不同。

## 画面/剪辑规则

产品君正片画面不是复杂包装，而是证据快剪。

素材优先级：

1. 官方页面录屏。
2. 产品演示/发布会画面。
3. 论文截图/榜单/数据图。
4. 模型效果图/生成视频片段。
5. 信息动效。
6. Pexels 泛素材。

Ian 的素材模块适配：

- 官方录屏：主证据。
- 新闻图文快讯录屏：事实补充。
- Pexels：只做情绪/场景过渡，不做主要证据。
- Codex 信息动效：用于没有好画面时，把事件做成信息卡、时间线、对比表。

每个信息点画面建议：

```text
2-4 秒：标题/官网/论文首页
3-6 秒：功能演示或关键截图
2-4 秒：数据/榜单/效果对比
1-2 秒：一句字幕判断
```

剪辑节奏：

- 画面切换快于普通口播。
- 每 8-20 秒完成一个信息点。
- 不要长时间停留在一张图。
- 字幕和画面必须说同一件事，不能只是装饰。

## 字幕规则

字幕不是逐字稿，而是一句理解提示。

推荐：

- 底部一行。
- 白字 + 深色描边/半透明底。
- 每屏只讲一个判断。
- 专业词后面立刻给人话解释。

例：

```text
不是又一个聊天机器人，而是能自己跑任务的员工。
它真正改变的是设计和代码之间的交接。
这类工具会先影响白领的重复流程。
```

## 音频/节奏规则

样本音频静音统计：

- 13 条样本语音密度基本在 0.992-1.0。
- 多数视频全片静音段只有 0-2 个。
- 说明它是连续信息流，而不是慢节奏讲解。

对 Ian 的建议：

- AI 配音默认语速略快，但不能糊。
- 句子要短，靠逗号/分句换气。
- 不需要重 BGM 抢信息。
- 转场音效少用，只在章节切换或封面钩子处使用。

## 商业引导逻辑

产品君样本里的直接商业引导不强。

它的商业逻辑是：

```text
稳定系列名
-> 每周筛选能力
-> 高频证据画面
-> 建立“我替你看完 AI 世界”的信任
-> 让观众关注/收藏/复看
```

Ian 可迁移为：

```text
我每天替你筛掉 90% 噪音
-> 留下最影响钱、工作、机会、判断的几件事
-> 给普通人能听懂的判断
-> 关注/收藏，明天继续看
```

结尾 CTA 不要太销售：

```text
今天这几件事，最值得记住的是 X。
我会继续帮你筛掉噪音，明天继续。
觉得有用可以先收藏，后面复盘会用到。
```

## 不要学习

- 不要复制封面蓝白块和人物素材。
- 不要把所有新闻都梗化。
- 不要为了猎奇牺牲事实准确。
- 不要让“最强/王炸/史诗”成为默认词。
- 不要只堆列表，必须给一条主判断。

## 给脚本工厂的生成指令片段

```text
参考产品君「一周 AI 大事」的表达方法，但不要复制其文案。

生成前先做事件排序：
1. 找出最有普通人处境感的事件。
2. 把它作为开头，不一定按时间顺序。
3. 把每个技术事件翻译成钱、工作、关系、效率、风险、机会中的一种。
4. 每条信息只保留一个判断句。
5. 为每条信息生成一个可剪辑的证据画面需求。

输出必须包含：
- 3 秒开头钩子
- 本期一句总判断
- 逐条信息点口播
- 每条对应字幕
- 每条素材建议：官方录屏 / 新闻截图 / Pexels / 信息动效
- 封面文案：系列标签 + 6-10 字强钩子
- 结尾轻 CTA
```

## 质量检查

生成后检查：

- 开头是否是普通人场景，而不是模型名？
- 第一条是否最抓人？
- 有没有 8-12 个信息点，或者按 Ian 设定的数量完整覆盖？
- 每条是否都有一句人话判断？
- 是否有至少 70% 画面可以用官方录屏/截图/信息动效支撑？
- 封面文案是否比标题更短更狠？
- 是否避免了纯营销号焦虑？
