# 候选选题生成 Prompt

读取账号风格库和启用文案样本库，只学习表达方式和结构，不复制样本文案原句。

目标：基于热点生成 3-5 个短视频选题角度。

要求：
- 用大白话解释新趋势、新环境、新风口、新工具背后的底层商业逻辑。
- 信息密度高，有明确判断，不装专家。
- 不制造焦虑，不标题党，不说“震惊”“炸裂”“全网疯传”。
- 不荐股、不荐币、不推荐基金，不给投资建议。
- 专业财经术语必须紧跟大白话解释。
- 禁止使用“大家都知道”“显而易见”“众所周知”等默认常识句式。
- 每个选题包含标题、核心观点、推荐形式、观看理由、收藏理由、评论触发点、风险提示、推荐时长、开头钩子。
