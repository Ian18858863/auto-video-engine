# Auto Video Engine

Auto Video Engine 是本地短视频自动化生产工作流工具。V1 目标是让系统自动抓取公开热点、清洗去重、评分、生成候选选题，并在用户确认关键决策后自动衔接脚本、素材任务、字幕、剪辑清单和成片导出任务。

> 当前仓库是持续开发中的公开开发版，部分流程仍在重构，默认使用 fake provider 进行本地验证。

## V1 内容形态

- 单选题深挖型：一个热点做一条视频。
- 多热点合集型：一天 3-5 个重要热点合成一条视频，按重要性排序，重点放前面。

## 安全边界

- 当前默认使用 fake provider 跑通流程。
- 不提交 `.env`，不读取真实 API Key。
- 公开热点采集只使用你本机 Chrome 正常登录态；不绕过验证码、不破解反爬、不批量下载视频。
- 不生成真实数字人，不自动发布、评论或私信。
- 热点抓取、去重、过滤、初步评分和页面展示不调用 AI。

## Windows 启动

- 双击 `启动全部.cmd` 同时启动后端和前端。
- 双击 `启动后端.cmd` 只启动后端。
- 双击 `启动前端.cmd` 只启动前端。
- 浏览器地址：`http://127.0.0.1:5173`

## 公开热点 CSV 采集

V1 已配置百度热搜、微博热搜、抖音热点、小红书公开发现页、B站热门、B站科技区排行、财联社电报网页版。Product Hunt 暂停，不在本轮采集。

B站默认走浏览器网页登录态采集；旧的 B站排行榜公开接口容易风控失败，当前默认关闭。

首次使用浏览器采集前，如果提示缺少 Playwright，在项目根目录运行：

```powershell
backend\.venv\Scripts\python.exe -m pip install playwright
```

然后双击：

```text
更新公开热点CSV.cmd
```

如果微博、抖音、小红书、B站显示未登录，先双击：

```text
登录热点采集浏览器.cmd
```

它会打开采集专用 Chrome，不采集、不自动关闭。登录完成后，手动关闭这个 Chrome 窗口，再运行 `更新公开热点CSV.cmd`。

采集结果会追加写入：

```text
exports/热点采集/browser_hotspots.csv
```

这个 CSV 可以用 Excel 打开。文件已存在时会追加新数据，并按链接去重。

采集规则：

- 默认低频手动采集；不要高频刷新。
- 如果登录态过期、出现验证码或安全验证，系统会停止该来源并提示重新登录。
- 采集字段：标题、链接、作者、发布时间、点赞数、评论数、采集时间。
- 能采集到的热点会同步进入热点池；某个来源失败不影响其他来源。

选题页的 `更新今日事件（含浏览器热点）` 会先运行浏览器热点采集，再运行公开源抓取，并重新生成候选事件。设置页的 `采集浏览器热点` 只运行浏览器来源。
